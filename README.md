## Learning Path

A practical progression through this collection is:

1. **Begin with HTTP reconnaissance** — identify the application's accessible services and technology stack.
2. **Fingerprint web applications** — recognize CMS platforms and gather useful version or implementation clues.
3. **Review robots.txt** — understand how publicly accessible metadata can reveal application paths.
4. **Practice file enumeration** — search for hidden files, directories, and PHP resources.
5. **Learn FFuf concepts** — automate controlled discovery of files and endpoints.
6. **Study parameter fuzzing** — investigate how parameters can reveal unexpected application behavior.
7. **Explore LFI** — understand Local File Inclusion and its information-disclosure implications.
8. **Practice SMB enumeration** — investigate network shares and exposed SMB resources.
9. **Connect the findings** — use reconnaissance results to understand the broader CTF attack surface.

## How to Use the Labs

1. Select a challenge from the direct-link index.
2. Read the challenge objective and authorized scope.
3. Begin with passive and low-impact reconnaissance where appropriate.
4. Identify technologies, services, files, directories, and parameters.
5. Use FFuf or other enumeration techniques only against the provided lab target.
6. Analyze LFI and information-disclosure behavior within the authorized environment.
7. Document useful findings and their security implications.
8. Avoid assuming that every discovered resource is vulnerable.
9. Review remediation and defensive controls after completing the challenge.
